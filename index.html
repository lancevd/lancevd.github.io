About

My research focuses on: software engineering, security, and AI. My goal is to build fundamental knowledge and algorithms to improve developers' productivity (e.g., code generation/recommendation, bug fixing) and ensure software quality (e.g., vulnerability detection and bug localization) effectively and efficiently.
